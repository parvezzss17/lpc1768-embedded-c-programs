# LPC1768 Embedded C Programs

A collection of hands-on Embedded C programs developed while learning
ARM Cortex-M3 microcontroller programming using the LPC1768 development board.

These programs were developed and tested using Keil and programmed onto
the microcontroller using Flash Magic.

## 🛠️ Hardware & Tools

- **Microcontroller:** NXP LPC1768
- **Architecture:** ARM Cortex-M3
- **Programming Language:** Embedded C
- **IDE:** Keil
- **Flashing Tool:** Flash Magic
- **Peripheral:** GPIO / LEDs

## 📂 Programs

| # | Program | Concepts |
|---|---|---|
| 01 | Single LED Blink | GPIO output, delay |
| 02 | All LEDs Blink | GPIO control, bit masking |
| 03 | Sequential LED Blink | GPIO control, bit shifting |
| 04 | LED Reverse Sequence | Loops, GPIO, bit shifting |
| 05 | LED Forward & Reverse | Loops, GPIO sequencing |
| 06 | LED Merge | Bitwise OR, GPIO control |
| 07 | LED Merge & De-merge | Functions, loops, bit manipulation |
